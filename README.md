## 폴더 구성

```
nipa_ai_eval/
├─ qa_app.py, spec_page.py      웹 화면 (Streamlit)
├─ spec_runner.py               시험 실행기 (질의 → 로그 → 채점)
├─ spec_eval.py, qa_eval.py     채점 로직, 조문 정규화, 버전 정보, 6단계 로그
├─ qa_runner.py                 AIPS 질의 전송 (SSE)
├─ spec_data/                   시험 데이터 (testset_ai*.csv, answer_ai*.csv, 조작적 정의서, 원본·선정내역)
├─ spec/                        실행 결과 (git 제외 — 서버·PC에만 있음)
├─ deploy/                      podman 배포 파일, 결과 동기화 스크립트
├─ tools/                       조문 DB 생성, 온톨로지 내보내기(DA2), 법령 원문 조회, DA2 실행기·구성지표 2-1~2-4 도구
├─ backup/                      이전 시험 데이터 백업
└─ 참고문서/                    규격서·시험의뢰서·수행계획서 PDF (git 제외)
```
